## Explanation
Three small web pages using basic JavaScript: functions, events, if/else,
a for loop and DOM methods. `index.html` links to all three pages.

| File | What it does |
|---|---|
| `lab4-q1.html` | Clicking **Change Message** changes the paragraph to "Hello there!" |
| `lab4-q2.html` | Checks if the number is lower than, higher than or equal to 10. Empty or non-number input shows "Please enter a valid number!" |
| `lab4-q3.html` | Clicking **Generate** builds a list from 1 to 5. The list is cleared first, so there are no duplicates. |

## How to run
1. Download or clone this repository.
2. Open `index.html` in a browser, or open `lab4-q1.html`, `lab4-q2.html` or `lab4-q3.html` directly.
3. No installation or internet needed.
